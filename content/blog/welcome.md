This is the first post on **Microbial Quanta** — a research site, project portfolio, and occasional blog about microbiology and the instruments I build to study it.

The site has a few sections:

- **[Research](/research/)** — the questions I'm working on
- **[Projects](/projects/)** — DIY scientific instruments with full build files
- **[Microelectronics](/microelectronics/)** — Arduino and Raspberry Pi work
- **[Publications](/publications/)** — peer-reviewed papers
- **About** — who I am and how to reach me

Everything is open. STL files, OpenSCAD source, firmware, analysis code — all downloadable, all reusable. If you build something based on what's here, I'd love to hear about it.
